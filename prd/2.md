# Roadmap

## CI/CD Integration
- Provide a GitHub Actions workflow and GitLab CI template for running scans on PRs
- Exit with non-zero status when policy violations are detected (fail the build)
- Support baseline mode: only report new findings introduced in the current diff
- Generate SARIF output for native GitHub Code Scanning integration

## Policy-as-Code
- Define project policies in a `.codestature.toml` config file
- Allow per-rule severity overrides (error, warn, ignore)
- Support allow/deny lists for licenses, CVEs, and complexity thresholds
- Enable org-wide shared policy files via remote URL or registry

## Reporting & Dashboards
- Generate HTML and JSON summary reports per scan
- Track findings over time with a local SQLite history database
- Provide trend charts for complexity, vulnerability count, and license drift
- Support exporting findings to Markdown for PR comments

## Secret Detection
- Scan source files and git history for hardcoded secrets (API keys, tokens, passwords)
- Built-in patterns for common providers (AWS, GCP, Stripe, GitHub, Slack)
- Support custom regex patterns defined in policy config
- Entropy-based detection for high-randomness strings
- Recommend `.gitignore` and pre-commit hook additions on detection

## Dependency Graph & Reachability
- Build a full inter-package dependency graph across the monorepo
- Determine reachability: flag CVEs only when the vulnerable code path is actually called
- Visualize the dependency graph as DOT/SVG output
- Detect circular dependencies and phantom (unused) dependencies

## Fix Suggestions & Autofix
- Suggest version bumps for dependencies with known CVEs
- Auto-generate pull requests with safe dependency updates
- Propose refactoring hints for functions exceeding complexity thresholds
- Provide inline code annotations with remediation guidance for SAST findings
