# Roadmap

## License Compliance
- Detect license types in dependency manifests (Cargo.toml, package.json, go.mod)
- Flag copyleft licenses (GPL, AGPL) when project uses a permissive license
- Generate a license summary report (SPDX identifiers)
- Warn on missing or unknown licenses

## Cyclomatic Complexity
- Parse source files to compute cyclomatic complexity per function
- Support Rust, Go, TypeScript, Python, and Java
- Flag functions exceeding a configurable threshold
- Show top N most complex functions in scan output

## SAST (Static Application Security Testing)
- Taint analysis for user input flowing into dangerous sinks
- Detect insecure deserialization patterns
- Check for path traversal vulnerabilities
- Identify unsafe use of eval, exec, and dynamic code execution
- Language-specific rules (e.g., unsafe blocks in Rust, prototype pollution in JS)

## SCA (Software Composition Analysis)
- Parse lockfiles (Cargo.lock, package-lock.json, go.sum, requirements.txt)
- Query CVE databases for known vulnerabilities in dependencies
- Flag outdated dependencies with available security patches
- Generate a dependency tree with risk annotations
