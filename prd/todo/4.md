# Roadmap

## Team & Organization Management
- Multi-tenant workspace with team-scoped projects and policies
- SSO integration (SAML, OIDC) for enterprise authentication
- Role-based access control: admin, auditor, developer, read-only
- Activity audit log for all policy changes, suppressions, and overrides

## Notifications & Alerting
- Webhook integrations for Slack, Microsoft Teams, and PagerDuty
- Configurable alert thresholds (e.g., critical CVE introduced, license violation)
- Digest emails with periodic summary of new findings across projects
- Escalation rules: auto-assign findings to code owners via CODEOWNERS mapping

## SBOM (Software Bill of Materials)
- Generate SPDX and CycloneDX SBOM documents from scan results
- Include transitive dependency resolution with provenance metadata
- Attach SBOM artifacts to CI builds and container images
- Diff SBOMs across releases to surface newly introduced components
- Validate SBOM completeness against actual build artifacts

## Container & Infrastructure Scanning
- Scan Dockerfiles for insecure base images and misconfigurations
- Analyze container image layers for embedded secrets and vulnerable packages
- Detect IaC misconfigurations in Terraform, CloudFormation, and Kubernetes manifests
- Flag overly permissive IAM policies, open security groups, and unencrypted storage
- Support OCI image scanning in registries (ECR, GCR, Docker Hub)

## API & Extensibility
- Public REST and gRPC API for programmatic access to scan results and policies
- Plugin SDK for authoring custom scanners and output formatters
- Event-driven architecture with pub/sub hooks for scan lifecycle events
- Terraform provider for managing policies and projects as infrastructure-as-code

## Benchmarking & Comparative Analysis
- Score projects against industry baselines (OpenSSF Scorecard, OWASP benchmarks)
- Compare security posture across teams, repos, or time periods
- Gamification: leaderboards and badges for teams improving their scores
- Executive summary view with org-wide risk heatmap and KPIs
